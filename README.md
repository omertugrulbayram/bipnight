# BiP Night 2026 · Case 3B · BiP Kelime

Turkcell Geleceği Yazanlar **BiP Night 2026** tasarım gecesi için hazırlanan, tıklanabilir HTML prototip.

**Canlı prototip:** https://omertugrulbayram.github.io/bipnight/

Telefon, tablet ve bilgisayarda çalışır. Kurulum gerektirmez.

## ⚠️ Ekip için: dosyalar birlikte çalışır
`index.html` tek başına gönderilirse BiP Kelime açılmaz, çünkü oyun `kelime-yeni.html` içinden yüklenir. Üç HTML dosyası **aynı klasörde** olmalı.

Projeyi almanın iki yolu:
- **ZIP:** bu sayfada yeşil **Code** düğmesi → **Download ZIP** → klasörü çıkar → `index.html`'i aç.
- **git:** `git clone https://github.com/omertugrulbayram/bipnight.git`

Dosya göndermek yerine canlı linki paylaşmak en kolayı: https://omertugrulbayram.github.io/bipnight/

## Dosyalar
- `index.html`: BiP 5.6'nın web kopyası. BiP Kelime, Kanallar'dan ve sohbetten bunun içinde açılır.
- `kelime-yeni.html`: yeniden tasarlanan BiP Kelime (oyun, seri ve dondurucu, bildirimler, liderlik, profil, erişilebilirlik, karanlık mod).
- `hareket-dili.html`: mikro animasyonların hareket dili sayfası.

## Nasıl denenir
1. Kanallar → Keşfet → 🎮 Oyunlar → BiP Kelime → **Oyna**
2. Üstteki "Yeni tasarım / Bugünkü" düğmesiyle önceki ve yeni tasarımı karşılaştır.
3. "🔔 Bildirim gelsin" ve "🌙 Koyu" düğmeleriyle bildirimi ve karanlık modu dene.
